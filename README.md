# CatLog 猫咪日志

记录猫咪的体重、每天的状态（食欲、饮水、精神、大小便、呕吐）、饮食、活动、健康事件、疫苗和驱虫、照片，以及疫苗本、体检报告这些文件。剪指甲、刷牙这些护理，能看到上一次是几天前；宠物保险能记下是哪家公司、谁在付、每月保费、额度用了多少还剩多少、哪天续保。两个人各用自己的 iPhone，一边记，另一边就能看到。

- 网页放在 GitHub Pages 上，添加到主屏幕后像 App 一样用。
- 记录存在你自己的 Google 表格里，照片和文件存在你 Google Drive 的「CatLog 猫咪日志」文件夹里。随时可以直接打开、导出。
- 不依赖任何 AI 账号或第三方服务。

当前版本：**1.1.0**（已经在用 1.0.0 的，看第四节「升级」）

## 一、部署（大约 20 分钟，只做一次）

和「家务打卡」是同一套做法，多了一步 Drive 授权。Google 的界面按英文写。

### 1. 建一张表格

用**个人 Gmail** 打开 <https://sheets.new>，建一张空表格，名字随意（比如「CatLog 猫咪日志」）。

### 2. 粘贴后端代码

1. 表格菜单 **Extensions → Apps Script**。
2. 把编辑器里原有的内容全部删掉，把发布包里的 **`Code.gs`** 全部内容粘贴进去。
3. 点上方的保存图标。左上角的项目名可以改成 `CatLog`。

### 3. 运行一次 `setup`

1. 编辑器上方的函数下拉框选 **`setup`**，点 **Run**。
2. 第一次会要求授权：**Review permissions** → 选你的账号 → 出现「Google hasn't verified this app」时点 **Advanced** → **Go to CatLog (unsafe)** → **Allow**。
   这是你自己的脚本，只有你能改，所以 Google 没有审核过它。
3. 授权的内容和原因：
   - **表格**：读写这张表格里的记录。
   - **Google Drive**：把照片和文件存进 Drive 里的「CatLog 猫咪日志」文件夹。Google 给脚本的 Drive 权限只有「全部文件」这一档，实际上脚本只在自己建的那个文件夹里建文件、读文件、把删掉的放进回收站。
   - **在表格里显示弹窗**：菜单里「生成初始化链接」的那个窗口。
4. 运行结束后，编辑器下方的 Execution log 里会出现「准备好了」。回到表格，下面多了 9 个工作表（另有一个隐藏的 `thumbs`）；Drive 里多了「CatLog 猫咪日志」文件夹（里面有「照片」「文件」两个子文件夹）。

### 4. 部署成网页应用

1. Apps Script 编辑器右上角 **Deploy → New deployment**。
2. 齿轮图标选 **Web app**。
3. **Execute as** 选 **Me**；**Who has access** 选 **Anyone**。
   （选 Anyone 是因为手机上的网页不登录 Google；能不能读写由链接里的口令决定。）
4. 点 **Deploy**，把 **Web app URL** 复制下来。它以 `/exec` 结尾。

### 5. 把网页放到 GitHub Pages

1. 在 GitHub 新建一个**公开**仓库，名字用 `catlog`。
2. 仓库页面点 **uploading an existing file**，把发布包 `catlog/` 文件夹里的**全部文件**拖进去（都在同一层，没有子文件夹），点 **Commit changes**。
3. **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，点 **Save**。
4. 等一两分钟，页面地址是 `https://你的用户名.github.io/catlog/`。
   按你现在的用户名就是 <https://rrrrroentsen.github.io/catlog/>。

仓库里没有任何口令和个人数据。`Code.gs` 也在里面，它不含口令（口令在 Apps Script 的脚本属性里）。

### 6. 生成两条初始化链接

1. 回到表格，刷新一下页面，菜单栏会多出 **CatLog**。
2. **CatLog → 生成初始化链接**。
3. 「接口地址」粘贴第 4 步的 Web app URL，「页面地址」粘贴第 5 步的页面地址，点「生成两条链接」。
4. 两条链接一人一条。链接里带着口令，用隔空投送、备忘录或私聊发给对方，不要发到公开的地方。

弹窗打不开时（同时登录了几个 Google 账号时会这样）：在 `Code.gs` 最上面的 `FALLBACK_API_URL` 和 `FALLBACK_PAGE_URL` 两行填上这两个地址，保存，运行函数 `printInitLinks`，到下方的 Execution log 里看链接。

### 7. 两部 iPhone 各做一次

1. 先把自己的那条链接**复制**好。
2. 用 **Safari** 打开链接（微信里打开的话，点右上角选「在 Safari 中打开」）。
3. 点 Safari 底部的分享按钮 → **添加到主屏幕**。
4. 从主屏幕打开 CatLog，把刚才复制的链接**粘贴**进去，点「开始使用」。
   iPhone 主屏幕上的 App 和 Safari 不共用数据，所以要在这里再粘贴一次。以后一直从主屏幕打开。
5. 第一部手机点「添加第一只猫」，填名字和生日。第二部手机打开就能看到。
6. 「设置 → 成员」里把名字改成自己的。

### 8. 让对方也能直接打开表格和文件夹（可选）

App 里看照片、取文件不需要这一步。想让对方也能直接在 Google 里看：把表格和 Drive 里的「CatLog 猫咪日志」文件夹**共享**给对方的 Gmail。文件详情里的「在 Google Drive 里打开」要有这个权限才打得开。

## 二、怎么用

- **今天**：猫咪的名片（年龄、到家第几天、最近体重）、提醒、今天的状态、护理（剪指甲、刷牙各是几天前）。没什么事就点「一切正常」，有状况点「逐项记录」。
- **加号**：体重、今日状态、照片和瞬间、饮食、活动和护理、健康事件、疫苗、驱虫、文件。
- **时间轴**：所有记录按日期排，可以按类型筛选；「异常」只看有状况的日子和健康事件。生日和到家纪念日会自动标出来。
- **成长**：体重曲线（可以拖着看每一次）、状态日历（点某一天可以补记或修改）、从小到大的对比、月龄相册。
- **档案**：疫苗、驱虫、护理、健康、保险、文件六栏。
- **设置**（右上角）：猫咪资料、自己的名字和颜色、体重单位、深浅色、同步状态。

### 护理：上一次是什么时候

剪指甲、刷牙、梳毛、洗澡、清耳朵五种。

- **记一次**：首页「护理」卡片上点那一种 →「今天做了」；或者「档案 → 护理」里点右边的「做了」。记错了马上点「撤销」。不是今天做的，点「补记以前的一次」，改日期。
- **看上一次**：首页卡片和「档案 → 护理」都直接写着「27 天前」。点名字能看到以前每一次的日期和是谁记的。
- **到时间提醒（可选）**：点名字，在「多久做一次」里选每天、每周、每两周、每月或每三个月。到了时间，首页的提醒里会出现「该剪指甲了」。不选就只是记着，不提醒。两只猫各定各的。
- 这些记录也在时间轴里（类型是「活动」），以前用「活动和护理」记过的剪指甲、刷牙也算在内。

### 保险

「档案 → 保险 → 添加保险」。只有保险公司的名字是必填的，其他有什么填什么：

| 填什么 | 说明 |
|---|---|
| 保险公司、计划、保单号 | |
| 谁在付 | 你、对方，或者一起付 |
| 每月保费、货币 | 卡片上会顺便算出一年是多少 |
| 年度额度 | 一年最多赔多少。不限额就空着 |
| 自付额 | 每个保单年度里自己先付的那部分（deductible） |
| 赔付比例 | 比如 80 |
| 本年度从哪天开始、下次续保日 | 填了开始日期，点「开始那天的一年后」会自动填续保日 |
| 已经用掉的额度、自付额已经抵掉的 | 只在不想一笔笔记理赔时才填，直接填总数 |
| 保单文件 | 保单的照片或 PDF |

**用了多少、还剩多少**有两种记法，可以混着用：

1. 每次理赔记一笔（保单卡片上的「记一笔理赔」）：什么事、日期、账单金额、保险赔了多少、其中抵自付额的部分，可以附上账单。还没赔下来的先不填赔付金额，状态是「已提交」；填了赔付金额就算「已赔付」；被拒的不计入已用。
2. 不想一笔笔记，就在保单里直接填「已经用掉的额度」。

卡片上的数字是这样算的：

- **已用** = 手填的已用 + 本年度里每笔理赔赔了多少（被拒的不算）。**还剩** = 年度额度 − 已用。
- **自付额已抵** = 手填的已抵 + 本年度理赔里抵掉的，最多算到自付额那么多。
- **本年度**从「开始」那天算到续保日的前一天；没填开始日期就按续保日往前一年。日期不在这个范围里的理赔收在「不在本年度的理赔」里，不计入。
- 离续保日不到 30 天，首页会提醒。续保日过了以后，卡片上有「已经续保了，顺延一年」：年度往后挪一年，手填的已用和已抵清零，重新开始算。

这些数字是照你填的内容算出来的，方便自己心里有数；实际额度以保险公司的为准。

几条规则：

- 疫苗和驱虫的「快到期」：离下次的日子不到间隔的四分之一时开始提醒，最多提前 30 天，最少 3 天。一年一针的提前 30 天，一个月一次的驱虫提前 8 天。下次的日期以医生给的为准，App 只帮你记着。
- 护理的「该做了」：定了「多久做一次」以后，离上一次满了那么多天就提醒；定了但从没记过的，也提醒。
- 提醒只在打开 App 时显示在首页，网页 App 不能推送通知。
- 照片会缩到最长边 1600 像素再上传（拍的文件是 2200 像素，字还能看清），一张大约 0.2–0.5 MB。PDF 等文件原样上传，单个不超过 12 MB。不支持视频。
- 删除都可以马上「撤销」。删掉的照片和文件在 Drive 的回收站里还能找回 30 天。
- 没有网络时照常记，联网后自动补传。右上角会显示还有几条没传。

## 三、数据在哪

表格里的工作表：

| 工作表 | 内容 |
|---|---|
| `members` | 两个成员的名字和颜色 |
| `pets` | 猫咪资料 |
| `entries` | 体重、日常状态、饮食、活动、健康事件、瞬间。`summary` 列是一句话说明，`kg` 列是体重（公斤），方便直接看和画图 |
| `shots` | 疫苗和驱虫 |
| `docs` | 文件的标题、分类、日期 |
| `media` | 每张照片、每个文件对应 Drive 里的哪个文件 |
| `settings` | 体重单位；每种护理「多久做一次」（`care_猫的编号_护理类型`，值是天数） |
| `policies` | 保险：公司、谁在付（`a`、`b` 或 `both`）、每月保费、货币、年度额度、自付额、赔付比例、开始和续保日期 |
| `claims` | 理赔：属于哪份保单、日期、什么事、账单、赔了多少、抵自付额的部分、状态（`sent` 已提交、`paid` 已赔付、`denied` 被拒） |
| `thumbs`（隐藏） | 照片的缩略图。内容很长，不用打开 |

护理没有单独的表：每一次都是 `entries` 里的一行（`kind` 是 `activity`，`summary` 列写着「护理：剪指甲」）。金额在表格里是数字，可以直接求和。

- 可以直接在表格里改格子（比如补一句备注），手机下次同步就能看到。
- 整行粘贴、删行这类大改动之后，在 App 的「设置 → 连接与数据」点一下「重新同步全部数据」。
- 不要删行。要删一条记录，在 App 里删，或者把那一行的 `deleted` 填成 `TRUE`。
- 备份：表格 **File → Download → Microsoft Excel**；照片和文件在 Drive 的文件夹里，可以整个下载。
- 手机上只有缓存。换手机、清了数据，重新打开初始化链接就都回来了。

## 四、升级

拿到新版本以后（比如从 1.0.0 到 1.1.0）：

1. **后端**：Apps Script 里把 `Code.gs` 整个替换成新的，保存。然后 **Deploy → Manage deployments → 铅笔图标 → Version 选 New version → Deploy**。
   不要点 New deployment：那样接口地址会变，两部手机都要重新初始化。只保存不发新版本的话，后端还是旧的。
2. **网页**：把新发布包 `catlog/` 里的文件**全部**上传到 GitHub 仓库，覆盖旧的，**一次提交**（全选了一起拖进去）。
3. 两部手机都联着网把 App 划掉重开一次。「设置」最下面会显示网页和后端各自的版本号，两个都是新的就好了。

不需要重新初始化手机，记过的东西、没传完的东西都在。先做哪一步都可以，中间的状态也能照常用：

- **网页是新的、后端还是旧的**：别的照常同步；保险那一栏会提示「后端要先更新」，这时候记的保险先留在手机上（右上角显示「N 条等后端更新」），后端发了新版本以后自动传上去。
- **后端是新的、网页还是旧的**（或者另一部手机还没更新）：旧网页照常用，只是看不到保险和护理板。
- **打开后显示「正在更新，还没装完整」**：手机拿到的几个文件不是同一个版本。联网以后点「再试一次」；一直这样，多半是仓库里的文件没传全，把发布包里的文件再全部上传一遍。

从 1.0.0 升级时可以顺手做一件事（不做也不影响使用）：在 Apps Script 里再运行一次 `setup`。它不动任何数据和口令，只把旧表格里数字列的显示格式刷新一遍（1.0.0 建的表里，整数会显示成「12.」这样带一个点）。新的两张表 `policies` 和 `claims` 不用手工建，第一次用到时自动出现。

## 五、常见问题

**右上角显示「稍后重试」。** 网络不好，或者 Google 那边临时没回应。会自己重试，记的东西不会丢。点一下那个小药丸，设置页里有具体原因。如果原因是「接口返回的不是数据」，检查第 4 步的 Who has access 是不是 Anyone。

**显示「需要重新初始化」。** 口令被重置过（表格菜单里的「重置口令」）。重新生成链接，在 App 里「粘贴新的链接」。这部手机上没传的记录会留着。

**同步有点慢。** Apps Script 每次请求要 1–3 秒，一张照片要几秒。界面是先变的，后台慢慢传。

**对方的照片我这边一开始是灰的。** 缩略图和原图第一次要从 Drive 取，取过一次就存在手机上了。

**想重置口令。** 表格菜单 **CatLog → 重置口令**，然后重新生成链接，两部手机都要重新粘贴。

**在 Safari 里用（没加到主屏幕）过一阵子要重新初始化。** Safari 会清掉 7 天没访问的网站数据。加到主屏幕就不会。

**换图标或者主屏幕 App 打不开。** 删掉主屏幕上的 App，重新从 Safari 添加，再粘贴一次初始化链接。

**Drive 空间。** 一千张照片大约 300 MB，占的是表格主人的 Google 空间（免费 15 GB）。

**想先看看样子。** 打开页面，点「先看看演示」。演示数据是编的，只存在这台设备上，不会碰你的表格。

**保险那一栏写着「后端要先更新」，或者右上角显示「N 条等后端更新」。** 网页已经是 1.1.0，表格那边的 `Code.gs` 还是 1.0.0。按第四节第 1 步把后端换成新的并发一个新版本。在那之前记的保险不会丢，留在这部手机上，之后自动传。

**保险的额度和保险公司 App 里的对不上。** 这里是照你填的理赔一笔笔加出来的。看看有没有漏记的、日期落在「不在本年度的理赔」里的，或者续保以后还没点「顺延一年」。图省事可以不记理赔，直接在保单里填「已经用掉的额度」。

**剪指甲记错了日子。** 时间轴里（或者点护理的名字，在「记过的」里）点开那一条，改日期或者删掉。
